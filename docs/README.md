# Documentation

Current documents use this authority order:

1. human direction;
2. [`VISION.md`](VISION.md);
3. accepted [architecture decisions](adr/README.md);
4. [`DESIGN.md`](DESIGN.md);
5. active [planning](planning/README.md); and
6. shipped code and tests.

The prior browser/Tauri product and its records are preserved under [`v0/`](../v0/). Those records
are historical and do not direct v1 work.
