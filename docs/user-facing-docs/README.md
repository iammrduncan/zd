# zd documentation

`zd md` gives long Markdown documents a calm reading surface without making you switch away from
the editable source. Start with the task you want to complete.

## Tutorial

- [Open your first document](tutorials/first-document.md) to learn the reading, navigation,
  editing, and saving loop by completing it once.

## How-to guides

- [Install on macOS](how-to/install-macos.md) to verify, install, update, or remove a release build.
- [Install on Windows](how-to/install-windows.md) to verify and run the x64 release installer.
- [Develop zd](how-to/develop.md) to run the browser surface or native shell and choose a useful
  verification command.

## Reference

- [CLI reference](reference/cli.md) lists launch forms, path rules, and exit behavior.
- Hold `Cmd+.` in the app (`Ctrl+.` on other platforms) for the live shortcut reference. It uses
  the same command registry that handles each key.
- [Design system](../../DESIGN.md) defines canonical type, colour, spacing, and motion values.

## Explanation

- [Architecture](explanation/architecture.md) explains why the product uses a web frontend on a
  thin native shell and where each responsibility stops.

## Documentation contributors

Read the [documentation standards](DOCUMENTATION_STANDARDS_A.md) before you add or substantially
change a user-facing page. Planning records, implementation reports, and release operations belong
outside this folder.
