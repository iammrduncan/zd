zd studio is a single view.

using `zd` alone in cli will open it in default home screen dashboard.

using `zd .` will open the current folder as a zd project.

zd allows you to view bdd, markdown viewer, todos, and other mini apps within a single context.

its default open home screen dashboard mode allows you to launch zd studio (the full thing i just described) or a specific mini app based on past openings of the other apps or create / open new folder context ets.

maybe we have some interactions available in studio that aren't available in min app modes.
