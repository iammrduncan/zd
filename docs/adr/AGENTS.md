# ADR instructions

Use the five-part Nygard structure: Title, Status, Context, Decision, Consequences.

- Record one durable architecture decision per file.
- Number decisions sequentially with four digits.
- Use `_H` only when human direction approves the decision.
- Supersede an accepted decision with a new ADR; do not rewrite its history.
- Keep execution steps, research transcripts, and feature status out of ADRs.
- Update `README.md` in the same commit.
