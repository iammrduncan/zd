## GitHub Release

`zd md` v0.1.0 is the first public build of a calm, keyboard-first Markdown reader and editor for
the long documents coding agents produce.

Markdown stays rendered and editable in one surface. Focus can follow a line, paragraph, or section;
typewriter motion keeps the current line in place; folder workspaces keep nearby documents within
reach. Saving writes ordinary Markdown files, with external-change detection and native filesystem
scope guarding the boundary.

This release includes separate DMGs and SHA-256 checksums for Apple Silicon and Intel Macs. The app
is ad-hoc signed but not notarized, so verify the checksum and follow the documented Gatekeeper step
before the first launch.

Download: https://github.com/iammrduncan/zd/releases/tag/v0.1.0
