# Agent findings

Things the agent noticed mid-session that are real but out of scope for the session it was in.

This is the agent's own queue. `docs/_objectives/FEEDBACK.md` belongs to the human and holds what they noticed
using the thing — the agent never writes there. Both feed `todo.txt` the same way; keeping them
apart is what makes the archive of human words trustworthy evidence.

Notes are moved out of here once they become tasks, same as the inbox.
