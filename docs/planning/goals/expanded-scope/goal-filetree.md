# File Tree Goal

Update and implement better file tree for zd.

AC:

1. Two tabs on file tree (Files and Changes)
2. Files - Able to see a line showing all files in current hierarchy of the file tree.
2. Files - able to filter filetree by search terms or file type.
3. Files - Able to scroll both vertically and horizontally.
4. Files - Includes file type icons.
5. Files - Files that are new, modified, or deleted are highlighted correctly (based on git)
6. Files - Files that are gitignored are greyed out.
7. Changes - Shows all files currently modified and not committed
8. Changes - rewind to view previous commits and their changes. 
8. Changes - compare two commits for changes.
9. Changes - Able to open file in file editor and see diff.
