# Threads goal

Threads are a way to organize and manage multilple terminals / agents. 

- Threads sit on left side of screen.
- can be collapsed down to just icons or hidden completely.
- one thread per terminal / agent.
- Shows if thread/terminal is busy or idle or complete waiting for you to "read" it.
- audio chime on thread complete.
- you can have many threads under a project.
- threads show thread name, status, if an agent cli is running (if so shows that agent icon)(warp shell does this too), and current worktree of that thread.
- Threads can be attached to current worktree or new worktree when created. If separate worktrees, clicking a thread swithces the projects focus to that worktree (meaning filetree updates etc).
