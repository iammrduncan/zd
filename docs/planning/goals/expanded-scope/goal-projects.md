# Projects goal

zd supports opening many folders at once. Each folder is a "project".

- Threads are organized by project.
- projects can be switched to via cmd+num (e.g. cmd+1, cmd+2, etc.)
- cmd click of project also switches to it.
- when viewing project the file/thread/filetree/changes tab etc change to be in context of that folder/project.
- You can open/add/remove projects easily and to the same session of zd.
