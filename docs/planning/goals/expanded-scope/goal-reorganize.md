# Reorganize Goal

Ok so we are going to reorient the vision of zd. 

Don't think of it as mini apps ever growing app. Don't think of it as zensuite.

Think of it as ZenDesk the agent workbench that is beautiful.

zd = zendesk. there is no `zd md` there is only `zd`.

We we have the following vision:

- Agent Threads
  - Terminal Agent (Or just terminal) (Immediate goal)
  - ACP Agent (Future goal)
  - ZD Agent (cause we gotta have our own at some point) (Not current scope)
- Current Open File
  - Markdown file = our current reader/editor.
  - Code file = codemirror editor.
- File tree
  - two tabs on file tree (directory, git)
  - File tree directory
  - search / filter
  - Git Changes tab
- Full theming option with multiple themes available, add new themes by installing a <name>.theme.config file into zd home config. Ships with our current theme + dark theme + dracula style theme by default.
- Projects
  - switch with cmd+num or win+num
- Global Hotkey
  - Bring up app on any screen with a global hotkey ("cmd+`" "or win+`"). When clicking off app it hides app.
- Make it as fast as possible, as little on memory and cpu as possible.

So we have one app, no bunch of mini apps, and it fits how I use my editor day to day.
